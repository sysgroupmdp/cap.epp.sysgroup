# S&S Group — Capacitaciones y EPP

Aplicación Streamlit para registrar capacitaciones, asistentes, firmas táctiles y entregas de EPP (Res. 299/11).

## Ejecutar localmente
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Publicar
Subir todos los archivos del proyecto a GitHub y desplegar `app.py` en Streamlit Community Cloud.

La base SQLite se crea automáticamente en `data/capacitaciones_epp.db`.
